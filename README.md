# CS4012 Data Representation and Modelling site

A static site built for the CS4012 Data Representation and Modelling
module, from the LM051 Computer Systems degree at the University of Limerick.

## What it is

`assignment` holds a site for a fictional company, UL Poultry Products,
with home, about, news, products, locations, quality assurance and
contact pages.

## Tech

- HTML and CSS

## Viewing

Open `assignment/index.html` in a browser.
